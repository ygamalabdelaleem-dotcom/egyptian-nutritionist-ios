# 🥗 خبير التغذية المصري (رفيق الشغل المكتبي) — iOS PWA

تطبيق آيفون ويب تقدمي (**iOS Progressive Web App**) مصمم خصيصاً لطبيعة **الشغل المكتبي والعمل عن بُعد** في مصر، حيث يعتمد أغلب اليوم على الجلوس الطويل وطلبات الدليفري أو أكل الشارع والمطاعم المصرية المشهورة.

---

## ✨ المميزات الرئيسية

1. **🥙 موسوعة أكل الشارع والمطاعم المصرية المشهورة**:
   - **فطار وفول وطعمية**: ساندوتشات فول بلدي، طعمية، جبنة قريش، فول بالبيض المسلوق، بطاطس (جاد / التابعي / عربيات الفول).
   - **كشري وطواجن**: علب كشري بأحجامها، كشري دايت عالي العدس والحمص، طواجن مكرونة بالفراخ (أبو طارق / التحرير / هند).
   - **مشويات وشاورما ودليفري**: نصف فرخة مشوية، شاورما فراخ سوري بالتومية، شاورما لحمة مصري، كفتة الحاتي، شيش طاووق (كرم الشام / أبو حيدر / الدهان / فرحات).
   - **أكل شعبي وبيتي وأسماك**: كبدة إسكندراني، سجق شرقي، حواوشي بلدي، سمك مشوي ردة، ملوخية، محشي مشكل، تونة مصفاة.
2. **🌾 عداد الألياف الذكي (Fiber Tracker) + رافعات الألياف**:
   - يراقب نسبة الألياف مقارنة بالسعرات الحرارية لمنع **الخمول بعد الأكل (Food Coma)** ومقاومة الإنسولين والكرش المكتبي.
   - يقترح إضافات سريعة عالية الألياف متوفرة بسهولة (سلطة بلدي، جرجير وخيار، ترمس وحمص الشام، جوافة وتفاح، زبادي بالشوفان وبذور الشيا).
3. **⚖️ متابعة متكاملة للعناصر الغذائية (Macros & Micros)**:
   - السعرات الحرارية، البروتين، الكربوهيدرات، الدهون الصحية.
   - العناصر الدقيقة: **الحديد** (للتركيز)، **الكالسيوم**، **البوتاسيوم**، ومراقب **الصوديوم (الأملاح)** للتنبيه عند أكل وجبات مالحة.
4. **💊 جدول المكملات الغذائية لموظفي المكاتب**:
   - مكملات مجهزة مسبقاً مع مواعيدها وعلاقتها بالأكل: **فيتامين د3 + ك2**، **أوميجا 3**، **ماغنيسيوم جليسينات**، **فيتامين ب المركب**، **ألياف السيليوم/البروبيوتيك**، مع إمكانية إضافة أي مكمل خاص بك.
5. **🤖 الخبير الغذائي الذكي (Google Gemini AI + المحرك المصري المحلي)**:
   - اكتب وجبتك بالعامية المصرية بحرية (مثلاً: *"كلت رغيفين حواوشي وسلطة طحينة"*) ليقوم بتحليل السعرات والألياف وإعطائك نصيحة عملية لمنع الخمول وقت الشغل.
   - يعمل **فوراً بدون إنترنت** عبر المحرك المصري المحلي، أو عبر ربط مفتاح **Google Gemini API** المجاني.
6. **🔔 منبهات ومتابعة يومية أثناء الشغل**:
   - تذكير شرب الماء كل ساعة، تذكير القيام والحركة وفرد الظهر كل 45 دقيقة، وتذكير سناك الألياف والمكملات مع دعم إشعارات الآيفون ومنبه صوتي لطيف.

---

## 📱 طريقة التشغيل والتثبيت على الآيفون (بدون Mac أو حساب مطور Apple)

1. ارفع هذا المستودع (Repository) على حسابك في **GitHub**.
2. من إعدادات المستودع على GitHub ادخل إلى **Settings -> Pages** واختر **GitHub Actions** (أو الفرع `main`) ليتم نشر التطبيق تلقائياً على رابط `https://<username>.github.io/<repo-name>/`.
3. افتح الرابط من متصفح **Safari** على جهازك الآيفون.
4. اضغط على زر **المشاركة (Share ⬆️)** في أسفل المتصفح ثم اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
5. افتح التطبيق من شاشة الآيفون الرئيسية ليعمل بكامل الشاشة (`Standalone Mode`) ويدعم العمل بدون إنترنت (`Offline Service Worker`).
